```bash

```

### Applying Updates
```bash
pip install --upgrade RISCV
```

### Rolling Back
```bash
pip install RISCV==<previous-version>
```

- **Feature updates:** Monthly release cycle
- **Breaking changes:** 6-month deprecation notice
